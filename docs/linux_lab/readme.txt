Kernel: The core of the operating system. It manages hardware (CPU, memory, devices), runs processes, and acts as the bridge between hardware and software.

FHS (Filesystem Hierarchy Standard): Defines the standard directory layout in Linux, e.g. /etc for configuration, /home for user files, /var for logs, /bin for essential commands


Shell: A command-line interpreter (e.g. bash) that takes the commands you type, passes them to the kernel for execution, and displays the results.
