# Screenshots

Evidence for each activity lives in its own subfolder (`activity-01` ... `activity-10`).

## Naming convention

`<activity-number>-<short-description>.png`, for example `05-kill-confirmed.png`.
The exact filenames expected by each activity README are listed in that README's *Screenshots* section.

## Tips for good evidence

- Show the **prompt and the command** together with its output.
- Zoom the terminal font so text is readable.
- Do not capture passwords or personal data.
- Use **PNG** format.
- Run `bash scripts/check_screenshots.sh` to see which images are still missing.
